# DESIGN.md — 화면 디자인 규칙

**원본**: Stitch 프로젝트 「Productivity (정보과학 프로젝트)」 (id `7167526685742322693`)의 디자인 시스템 **Serene Academic Workstation**.
Stitch에서 첫 화면('오늘')을 만들 때 Stitch가 함께 만든 디자인 시스템이다. 코드의 색·글꼴·둥글기는 이 문서를 Tailwind 설정 한 곳에 옮겨서 쓴다.
화면 스크린샷은 `../2회차/stitch_화면/`, 만든 과정은 `../2회차/stitch_프롬프트_기록.md`.

> Stitch 화면에는 있지만 기능 목록에 없는 것(집중 모드, 학습 시간, 백링크 그래프 등)은 만들지 않는다. 모양만 가져온다.

## 분위기
공부하는 학생을 위한 조용한 책상. 오래 봐도 눈이 편한 흰색·슬레이트 톤이고, 그림자 대신 아주 얇은 테두리로 영역을 나눈다. 새까만 `#000000`은 쓰지 않는다.
색은 과목·카테고리·D-Day를 구분할 때만 쓴다.

## 간격
기본 4px 단위. 카드 안 여백 20px, 화면 좌우 여백 폰 16px / 데스크톱 32px, 사이 간격 폰 20px / 데스크톱 24px.

## 배치
- 데스크톱: 왼쪽 사이드바 240px, 본문 최대 1440px.
- 폰(768px 미만): 사이드바 대신 아래쪽 탭 막대.

## 그림자와 테두리
- 기본은 테두리 `1px solid rgba(226, 232, 240, 0.8)`.
- 카드: 거의 안 보이는 그림자 `0 1px 3px 0 rgba(15,23,42,0.03)`.
- 창·드롭다운만 조금 진한 그림자 `0 10px 25px -5px rgba(15,23,42,0.08)`.

## 부품
- **주요 버튼**: 바탕 `#1e293b`, 흰 글자, 높이 38px. hover `#334155`.
- **보조 버튼**: 바탕 없음, 얇은 테두리, 글자 `#334155`. hover 바탕 `#f8fafc`.
- **아이콘 버튼**: 32×32px, 아이콘 `#64748b`, hover 바탕 `#f1f5f9`.
- **입력칸**: 흰 바탕, 테두리 `#cbd5e1`, 안내 글자 `#94a3b8`. 포커스 때 테두리 `#64748b`와 옅은 링.
- **체크박스**: 18px, 체크하면 `#334155`로 채우고 글자에 취소선, 글자색 `#94a3b8`.
- **시간표 블록**: 과목 파스텔 바탕 + 왼쪽 3px 진한 막대.
