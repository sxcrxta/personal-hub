# 오류 기록 (trial-log)

작업하다 실제로 생긴 문제만 적는다. 형식: **문제 → 시도 → 결과**.

---

## 2회차 (2026-09-28)

### 1. 개발 서버 포트가 이미 쓰이고 있었다
- **문제**: 미리보기 서버를 5173번 포트로 켜려 했는데 "Port 5173 is in use"가 떴다. 확인해 보니 예전에 만든 다른 앱의 개발 서버가 그 포트를 쓰고 있었다.
- **시도**: 그 서버를 끄지 않고, 이 프로젝트는 5180번 포트를 쓰도록 미리보기 설정을 바꿨다.
- **결과**: 해결. 두 서버가 같이 켜져 있어도 된다.

### 2. FullCalendar 패키지 버전이 서로 달랐다
- **문제**: `npm install`로 FullCalendar를 설치했더니 `@fullcalendar/react`만 7.1.0이고 나머지(core, daygrid 등)는 6.1.21로 깔렸다. 버전이 섞이면 달력이 제대로 안 뜰 수 있다.
- **시도**: `@fullcalendar/react@^6.1.21`로 다시 설치해서 전부 6 버전으로 맞췄다.
- **결과**: 해결. 일·주·월 보기와 끌어서 만들기·옮기기가 된다.

### 3. lint 경고 두 개 (렌더 중 시간 읽기, effect 안에서 상태 바꾸기)
- **문제**: `npm run lint`에서 경고가 나왔다.
  - `src/hooks/useMemos.ts` — 화면을 그리는 도중에 `Date.now()`를 불러서, 그릴 때마다 결과가 달라질 수 있다.
  - `src/components/calendar/useCalendarScreen.ts` — 주소(`?event=`)를 읽어 effect 안에서 편집 칸 상태를 바꿔서, 화면을 한 번 더 그리게 된다.
- **시도**: 워커 확인 시각은 상태로 두고 30초마다 갱신하게 했다. 주소로 여는 일정은 처음 상태를 만들 때 바로 넣게 바꿨다.
- **결과**: 해결. 경고 0개.

### 4. 폰에서 한글이 단어 중간에서 끊겼다
- **문제**: 375px 폭에서 "볼트 폴더 이 / 름"처럼 단어 중간에서 줄이 바뀌었다.
- **시도**: 전체 기본 스타일(`src/index.css`)에 `word-break: keep-all`을 넣고, 긴 경로는 `overflow-wrap: break-word`로 줄이 바뀌게 했다.
- **결과**: 해결.

### 5. 일정 상세 패널에서 '끝' 시각 칸이 잘렸다
- **문제**: 340px 패널에 날짜·시작·끝 세 칸을 한 줄에 넣었더니 시각 칸("오전 10:15")이 넓어서 끝 칸이 밖으로 밀려났다.
- **시도**: 날짜는 한 줄을 다 쓰고, 시작·끝만 두 칸으로 나눴다.
- **결과**: 해결.

### 6. 알림 막대 문구의 조사가 틀렸다
- **문제**: 할 일을 지우면 "'동아리 보고서 초안 검토'을 지웠어요"처럼 받침 없는 제목에 '을'이 붙었다.
- **시도**: 제목을 빼고 "할 일을 지웠어요" / "하위 할 일을 지웠어요"로 바꿨다.
- **결과**: 해결.

### 7. Vercel이 `.gitignore`를 고쳤다
- **문제**: `vercel link`를 했더니 Vercel이 `.gitignore` 맨 아래에 `.vercel`과 `.env*`를 추가했다. `.env*`는 나중에 올려야 할 `.env.example`까지 막는다.
- **시도**: 기존 규칙(`.vercel/`, `.env`, `.env.*`, `!.env.example`)만으로 `.env.local`과 `.vercel/`이 무시되는지 `git check-ignore`로 확인한 뒤, 추가된 두 줄을 되돌렸다.
- **결과**: 해결. 비밀 파일은 여전히 올라가지 않는다.

### 8. 빌드 결과 JS 파일이 500KB를 넘는다는 경고
- **문제**: `npm run build`에서 "Some chunks are larger than 500 kB" 경고가 나온다. 마크다운·달력 라이브러리가 한 파일에 들어가서다.
- **시도**: 아직 없음. 동작에는 문제가 없다.
- **결과**: 진행 중. 화면별로 나눠 불러오는 방법(코드 분할)을 나중에 검토한다.

### 9. 화면 없는 Chrome으로 스크린샷을 찍다가 일정 화면에서 멈췄다
- **문제**: 회차 끝 스크린샷을 `Chrome --headless --virtual-time-budget`으로 찍었는데, 오늘 화면만 찍히고 일정 화면에서 5분 넘게 끝나지 않았다. 달력의 '지금 시각' 표시가 계속 움직여서 페이지가 끝났다고 판단하지 못한 것 같다.
- **시도**: 멈춘 작업을 끄고, 정해진 시간(1.5초)만 기다렸다 찍는 Playwright 방식으로 바꿨다.
- **결과**: 해결. `docs/screenshots/회차2/`에 8장.

## 3회차 (2026-10-08)

### 1. Supabase 새 프로젝트가 만들어지지 않았다
- **문제**: `personal-hub` 프로젝트를 만들려 하자 "무료 프로젝트 2개 한도에 걸렸다"는 오류가 났다. 쓰지 않던 일시정지 프로젝트를 지웠는데도 같은 오류가 났다.
- **시도**: 한도는 조직마다가 아니라 계정 전체 기준이었다. 다른 조직(`integrated-service`)에 켜진 프로젝트가 하나 더 있었다. 잘 안 쓰는 `oj-tracker`를 일시정지했다.
- **결과**: 해결. 서울 리전에 `personal-hub`를 만들었다. `oj-tracker`는 데이터가 남아 있어 나중에 다시 켤 수 있다.

### 2. 가입 인증 메일의 링크가 열리지 않는 주소로 갔다
- **문제**: Supabase의 기본 Site URL이 `localhost:3000`이라서 인증 메일 링크가 열리지 않는 주소로 넘어갔다.
- **시도**: 대시보드 Authentication → URL Configuration에서 Site URL을 Vercel 주소로 바꾸고, 개발 주소를 Redirect URLs에 넣었다. 이미 받은 메일은 링크를 누르는 순간 Supabase 서버에서 인증이 끝나므로, 오류 화면은 닫고 로그인하면 됐다.
- **결과**: 해결.

### 3. 저장이 잘 된다고 생각했는데 DB에는 값이 없었다
- **문제**: 설정 창에서 볼트 폴더를 바꾸고 새로고침했을 때 값이 남아 있었는데, DB를 확인하니 그대로였다. 아직 push하지 않아서 Vercel 주소에는 2회차 코드(localStorage)가 돌고 있었고, 그 화면에서 테스트했던 것이다.
- **시도**: 새 코드가 도는 개발 주소(`localhost:5180`)에서 다시 테스트하고, DB 값을 직접 확인했다.
- **결과**: 해결. "화면에 남아 있다"와 "DB에 저장됐다"는 다른 것이라, 이후 테스트는 DB 기록으로 확인했다.

### 4. 맥북 저장 공간이 꽉 차서 명령이 하나도 실행되지 않았다
- **문제**: Vercel 환경변수를 넣으려고 `npx vercel`을 실행하자 `ENOSPC: no space left on device`가 나고 이후 모든 명령이 실패했다.
- **시도**: 휴지통과 큰 파일을 정리해 1.5GB를 비웠다.
- **결과**: 해결. 다만 여유가 적어서 더 비워 둘 필요가 있다.

### 5. 일정에서 할 일을 만들면 "저장하지 못했어요"가 떴다
- **문제**: 일정 제목을 고친 직후 "이 일정으로 할 일 만들기"를 누르자 저장 실패 알림이 떴다. 서버 기록을 보니 일정 저장 요청이 409로 거부됐다. 바뀐 순서대로 DB에 보내도록 만들었는데, 제목을 고친 일정이 먼저 줄을 서 있어서 **아직 없는 할 일을 가리키는 일정**이 먼저 갔기 때문이다. 할 일은 따로 저장돼서 연결 안 된 할 일이 두 개 생겼다.
- **시도**: 바뀐 순서가 아니라 저장소를 만든 순서(할 일 목록 → 할 일 → 학업 → 일정)로 보내게 바꿨다. 다른 것을 가리키는 쪽이 항상 나중에 간다.
- **결과**: 해결. 다시 해 보니 할 일이 먼저, 일정 연결이 나중에 저장됐다.

### 6. 공부 항목을 캘린더에 배치했는데 "이미 모두 캘린더에 있어요"라고 나왔다
- **문제**: 배치 버튼은 공부할 날이 오늘이거나 지난 항목만 올린다. 공부할 날이 미래인 항목만 있을 때 올릴 게 0개인데도 "이미 모두 캘린더에 있어요"라고 잘못 알려 줬다(2회차 코드).
- **시도**: 아직 없음. 공부할 날을 오늘로 바꾸고 배치하면 제대로 올라가는 것은 확인했다.
- **결과**: 진행 중. 올릴 항목이 없을 때의 문구를 따로 나눌 예정.
